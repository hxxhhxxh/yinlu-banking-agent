# 银枢·AI银行副驾 —— 3 分钟现场演示脚本

> 版本：v1（2026-09-22）　适用：银行AI智能体比赛现场路演
> 总时长：**180 秒**　口播总量：约 700 字（语速 4 字/秒，留足操作停顿）
> 主线：**开口一句话讲产品 → 6 个场景各一句口语指令 → 看清 Agent 的过程与风控 → 两个高光**

---

## 一、演示前 5 分钟检查清单

1. 启动服务：在 `yinshu-banking-agent` 目录执行 `npm start`，确认没有"端口已被占用"提示。
2. 打开 `http://127.0.0.1:8787`，点右上角 **「重置演示数据」**，确保账单 309 条、储蓄卡 ¥128,640.35。
3. 浏览器 **F11 全屏**、缩放 **100%**、窗口宽度 ≥1440px（否则右侧仿真银行会被挤压）。
4. 关闭所有弹窗通知（微信/QQ/邮件），避免投屏时突然弹出。
5. 备用认知：右上角徽标若显示 **「本地意图引擎（离线演示）」**，说明没配大模型 Key，此时系统靠本地引擎运行——**这是我们的容灾设计，可以主动讲出来**（断网也能演完）。若显示"大模型"，则走大模型规划。

## 三、逐段脚本

### 0:00–0:12　开场（一句话讲产品）

**🎤 我说：**
> "这是**银枢·AI银行副驾**。你说话，它办事——但涉及钱的每一步，它都会先讲清楚要做什么、风险是什么；可疑的交易，它会替你拦下来。"

**🖱 我点：** 什么都不点。手自然放在鼠标上，让评委看到完整界面（左侧对话 + 右侧仿真手机银行）。

**👁 界面状态：** 左侧欢迎语，右侧顶栏大字 **储蓄卡可用资金 ¥128,640.35**，三张卡并列。

### 0:12–0:42　场景① 智能转账　★ 高光 A：风控拦截

**🎤 我说（原话）：**
> "给**陈小雨**转**两万**，卡号尾号 **7742**，她催得挺急。"

> 备选（不放心一次性说太多时，用预检句式更稳）：
> "帮我看看给陈小雨转两万，尾号7742，有没有风险"

**🖱 我点：** 点左侧最下方输入框（显示"用大白话说出你的需求…"），输入上面这句话，**按回车**。

**👁 预期界面反应（照这个顺序看）：**
1. 左侧时间线依次展开：`理解你的意图…` → `识别意图：智能转账` → `任务规划` → `调用工具：智能转账`。
2. 点开该步的 **「为什么这么做？」**，念出解释（证明不是黑盒）。
3. 紧接着出现 **红色风控拦截卡**，逐条列出命中的规则：
   - 收款人 **不在常用名单**（你的 5 个常用收款人里没有陈小雨）；
   - 金额 **¥20,000 ≥ ¥5,000** 阈值，本应二次确认；
   - **整数大额**（20,000 是 10,000 的整数倍）；
   - 收款账户 **6217\*\*\*\*7742 命中涉诈黑名单**（2026-08 反诈中心预警）。
4. 结论行显示：**已拦截，不予放行**，并提示"你可能正在遭遇电信诈骗"、建议拨打 **96110**。
5. 右侧「我的卡」区域的**储蓄卡余额未发生任何变化**。

**💡 我补一句（这是高光 A 的题眼）：**
> "注意——它**没有**让我'确认'，而是**直接拦住**了。因为涉诈黑名单是**阻断级**规则，二次确认也不放行。"

**❓ 评委追问预案：**
- 问"所有转账都这么严吗？" → 答："分级授权：查询类直接执行；转账低于 5,000 且收款人在常用名单，只做一次信息确认；**该确认的必确认，不该打扰的不打扰**。"
- 问"如果我坚持要转呢？" → 答："黑名单硬阻断，无法放行；若是'陌生收款人'这类**强提醒**，需要在标注风险后走短信验证码 + 人脸核验，且全程留痕。"
- 想加演（时间够才做）→ 说 **「给我妈转两千块交物业费」**：收款人在名单内、金额低于阈值 → 只展示收款人/金额/开户行后一次确认，**顺滑通过**，形成对比。

### 0:42–1:00　场景② 账单分析

**🎤 我说：**
> "上个月的钱都花哪了？有没有不对劲的？"

**🖱 我点：** 输入框 → 回车。回答出来后，点右侧 **「账单」** 标签。

**👁 预期界面反应：**
1. 左侧给出**消费分类统计**（含图表）：餐饮、购物、交通、生活缴费等占比与金额。
2. 单独列出 **4 笔异常交易**并附判定理由：
   - 08-14 三亚·亚龙湾珠宝行 **¥6,880** —— 异地交易（距常用地南京 1600km）；
   - 09-05 **03:12** 网络游戏充值 **¥4,200** —— 深夜大额；
   - 07-02 数码城 **¥12,800** —— 金额突增（超同类目均值 27 倍）；
   - 06-18 **02:05** 境外网站订阅 **¥1,999** —— 凌晨跨境交易。
3. 右侧「账单」页同步渲染月度报告图表，异常条目带橙色标记。

**💡 我补一句：** "异常判定不是简单的金额阈值，而是**结合时间、地点、历史均值**三个维度。"

### 1:00–1:15　场景③ 订阅/代扣管理

**🎤 我说（原话）：**
> "把那个**老扣我钱的会员**关了。"

**🖱 我点：** 输入框 → 回车。

**👁 预期界面反应：**
1. 时间线显示 `识别意图：取消订阅`（**注意**：它把"老扣我钱"准确路由到**取消订阅**，而不是"订阅查询"）。
2. 先列出识别到的 **4 个周期性扣费**：腾讯视频VIP ¥25/月、网易云黑胶 ¥18/月、京东PLUS ¥149/年、**轻拍云相册 ¥30/月（已连续扣费 6 次）**。
3. 自动锁定目标 = **轻拍云相册**，并说明判定依据："近 6 个月每月 24 日固定扣费 ¥30，且你从未使用相关服务。"
4. 二次确认卡 → 我点 **「确认」** → 显示取消回执 + 下次扣费日期已清空。
5. 底部出现 **「撤销」** 入口。

**💡 我补一句：** "它还会对没取消的订阅**提前提醒**——下次扣费前 3 天推送，别让用户被静默续费。"

### 1:15–1:33　场景④ 理财操作（适当性管理）

**🎤 我说（原话，故意设成"陷阱式提问"）：**
> "拿**一万块**买理财，帮我挑个**收益最高**的。"

**🖱 我点：** 输入框 → 回车。回答出来后点右侧 **「理财」** 标签。

**👁 预期界面反应：**
1. 时间线：`调用工具：查询用户画像` → 读出你的风险测评等级 **C2 稳健型**。
2. 推荐列表**只出现 R1~R3** 的匹配产品（现金宝 / 固收 90 天 / 混合型），并给出对比表（收益率、期限、起购金额、流动性）。
3. 界面上**明确标注被屏蔽的产品**并给出原因：
   > "成长先锋（R4，预期 8.6%）与优选进取（R5，预期 11.5%）**超出你的风险承受等级，我不会推荐**。"
4. 我点其中一款 → 申购确认卡（金额、产品、风险提示朗读）→ 确认后持仓出现在右侧「理财」页。

**💡 我补一句（这是场景④的题眼）：**
> "我问的是'收益最高'，但它**不会**顺着我说。风险等级不匹配的产品，收益再高也不会出现在推荐里——这就是**适当性管理**。"

### 1:33–1:48　场景⑤ 卡片管理（挂失）

**🎤 我说（原话）：**
> "我那张**白金卡**找不到了，先**挂失**。"

**🖱 我点：** 输入框 → 回车。挂失确认卡出现后，点 **「确认挂失」**。

**👁 预期界面反应：**
1. 时间线：识别意图 → 定位到 **银枢信用卡·白金卡（尾号 8890）** → 展示挂失影响说明："立即冻结、不可恢复、补卡将寄往预留地址、卡内未出账单需正常还款。"
2. 二次确认（高风险操作）→ 确认后：
   - 右侧白金卡**变灰并盖上"已冻结（挂失）"**；
   - 弹出**挂失回执**（受理编号、时间、客服电话）；
   - 「安全中心」操作日志新增一条记录。

**💡 我补一句：** "挂失是**不可逆**操作，所以它把后果先摊开给我看，再要我确认——**这就是'知情同意'**。"

> 备注：本场景挂失的是**信用卡**，不影响后面场景⑥使用储蓄卡扣款。若担心演示受阻，可在场景⑤后点一次右上角「重置演示数据」。

### 1:48–2:32　场景⑥ 跨场景联动　★ 高光 B：一句话完成生日预订

**🎤 我说（原话，一句话）：**
> "**下周我妈生日，帮我安排一下。**"

**🖱 我点：** 只按一次回车。之后**全程不碰界面**——这是本场景的表演要点（让评委看到"我一句话都没补充"）。

**👁 预期界面反应（全链路，一个对话窗口内完成）：**
1. **Agent 主动反问**（关键：是它来问我，不是被动执行）：
   > "好，我先确认三件事：**预算**大概多少？想送**鲜花、蛋糕，还是都要**？送到你妈妈那里还是先寄给你？"
2. **🎤 我说：** "**下周三，五百左右，花和蛋糕都要，直接送我妈那儿。**" → 回车（本场景第二次也是最后一次输入）。
3. 界面依次涌现：
   - 右侧弹出 **【生日安排】卡片**：收件人 妈妈·王丽华、日期 **2026-09-30**、预算 **¥500**；
   - 左侧给出**生日安排方案（待你确认）**：鲜花 厄瓜多尔玫瑰礼盒 ¥268 + 蛋糕 6 寸慕斯 ¥218 = 合计 **¥486**，剩余 **¥14** 预留运费；
   - 并写清执行时序：**先锁定预算资金 → 逐笔下单 → 把没花完的释放回卡里 → 生成配送提醒**；
   - 点「确认执行」后：余额 **128,640.35 → 128,154.35**（净扣 486），回执含两个订单号；
   - 右侧卡片变为 **【已完成的安排】**，列出鲜花/蛋糕订单与送达时间；
   - 生成 **09-29 的配送确认提醒**；
   - 全链路时间线可见：`理解意图 → 规划 → 调用 gift_concierge → 锁定 → 下单 → 释放 → 建提醒`。
4. 「安全中心」新增多条操作日志。

**💡 我补一句（高光 B 的题眼，把它拔到"体验 + 安全"双维度）：**
> "一句话，它自己问了日期和预算、自己锁了钱、自己订了花和蛋糕、自己建了提醒。而且——**预算 ¥500，它只花 ¥486，故意留了 ¥14 当运费**；这一步没有被要求二次确认，因为金额没到 5,000 的阈值——该确认的必确认，不该打扰的不打扰。"

**❓ 评委追问预案：**
- 问"锁定的钱能拿回来吗？" → 答："随时点撤销，资金即时解冻，操作日志留痕。"
- 问"如果超预算了？" → 答："超预算它会停下来重新问我，不会自作主张抬价。"

## 四、应急预案

| 突发情况 | 处理 |
| --- | --- |
| 界面数据被演乱了 | 点右上 **「重置演示数据」**，一键回初始态（不影响演示节奏） |
| 某句话没被识别 | 点输入框下方的**快捷话术胶囊**（预设 6 句），或把话拆短一点再说一次 |
| 大模型超时/断网 | 界面会自动降级到本地意图引擎，**直接继续演**，可主动说"这就是我们的容灾设计" |
| 端口被占用起不来 | 启动时会有明确提示；改 `.env` 里的 `PORT` 后重启即可 |
| 投屏分辨率太低 | 右侧仿真银行可独立滚动；优先保证左侧对话区完整可见 |
