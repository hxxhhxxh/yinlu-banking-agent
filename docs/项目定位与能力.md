# 银枢·AI银行副驾 —— 项目定位 / 能力 / 应用场景

> 用途：对外介绍、答辩开场、方案一页纸、团队对齐。所有数字均来自本项目实测。

---

## 一、一句话定位

**一个"有边界"的银行智能体：把风控、适当性与合规留痕做进 Agent 的能力边界——让 AI 能把事办完，但办不了不该办的事。**

### 1.1 300 字精简版（可直接用作作品简介/开场）

「银枢·AI银行副驾」是面向青年客群的手机银行 AI 智能体：一句话即可完成意图理解、任务规划与工具执行，覆盖转账、账单分析、理财、卡片管理、订阅取消与跨场景预订（说"下周我妈生日"，它自动锁资金、订鲜花蛋糕并建提醒）。

定位是把风控与适当性做成 Agent 的能力边界，而非免责声明：10 条风控规则前置判定，涉诈黑名单阻断级拦截、不给确认入口，≥5000 元强制二次确认与验证码，适当性不匹配连推荐都不给，六类操作全程留痕。

已工程化验证：264 项自动化断言、零依赖可离线运行、异常识别独立复现埋点且零误报。可落地于手机银行副驾、坐席辅助与反诈前置拦截，也可作为行内其他 Agent 的安全底座。

## 二、三层定位

### 2.1 产品定位

面向**青年客群（18–35 岁）**的**手机银行 AI 副驾**。不是"问答式客服"，而是能真实完成转账、理财、卡片、订阅与跨场景服务预订的**执行型助手**；凡涉及钱的步骤，先讲清"做什么、多少钱、风险是什么"，再由用户确认。

### 2.2 技术定位

一个**受约束的银行 Agent 参考实现**（Governed Banking Agent）。架构上把智能体拆成五层，边界清晰：

| 层 | 职责 | 关键约束 |
| --- | --- | --- |
| 意图层（本地意图引擎 / 大模型） | 听懂人话、规划步骤 | 只做规划，**不直接改数据** |
| 工具层（25 个银行工具） | 声明每一项能力 | 每个工具标注风险等级与是否需二次确认 |
| 门禁层（风控规则引擎 + 适当性） | 判定能不能做 | 硬阻断 > 业务拒绝 > 二次确认 > 直接执行 |
| 动作层（待确认单 / 验证码 / 执行） | **唯一发生资金变动的地方** | 未确认绝不执行，执行前再校验一次 |
| 审计层（全程留痕 + 对话持久化） | 记录发生了什么与为什么 | 六类结果全部入库，重启不重号 |

### 2.3 生态位：与相邻形态的区别

| 形态 | 能做什么 | 缺什么 | 本作品 |
| --- | --- | --- | --- |
| 银行智能客服 | 回答产品问题、引导入口 | 不能办事、不碰资金 | 能真实执行业务并守住边界 |
| 通用聊天机器人 | 对话流畅、可写代码 | 没有业务账本、不承担后果 | 每一步都落在真实账本与审计上 |
| 流程自动化（RPA/脚本） | 固定流程稳定执行 | 无法处理模糊口语与例外 | 模糊口语 + 缺信息时主动追问 |
| 普通"AI + 工具调用"演示 | 能调工具、能演示 | 风险操作也照做 | 该拦的拦得住、该拒的拒得掉、拒绝也留痕 |

## 三、能力清单

### 3.1 交互能力

1. **模糊口语理解**：支持"给我妈转两千块交物业费""把那个老扣我钱的会员关了"等表达；能从一句话中提取人名、金额、日期、分类、卡号尾号，且互不干扰（"每周1号""四个人"不会被当成金额）。
2. **多轮追问与上下文承接**：信息不全时**一次问全**（不逐步骚扰）；下一句"下周三，五百左右，花和蛋糕都要"会被正确承接为补充信息。
3. **过程可见**：每一步都以 `理解意图 → 任务规划 → 调用工具 → 执行结果` 呈现，可展开"为什么这么做"。
4. **流式回复 + 界面实时联动**：查到什么，界面就显示什么（卡片高亮、交易列表整批联动、异常卡片定位）。
5. **双引擎容灾**：默认本地意图引擎（断网可用），配置大模型后自动切换；大模型超时自动降级，演示不中断。

### 3.2 业务能力（六大场景 / 25 个工具）

| 场景 | 能力 |
| --- | --- |
| 智能转账 | 收款人模糊匹配、转账前关键信息展示、二次确认、定时转账、AA 拆分收款、T+0 撤销转账、转账台账 |
| 账单分析 | 分类统计、环比、时段分布、商户榜、年度报告；**评分制异常识别**（深夜/异地/境外/金额突增/超大额） |
| 理财操作 | 风险测评（5 题 → C1~C5）、适当性过滤推荐与对比、申购/赎回（三道门校验 + 风险提示朗读）、持仓查询 |
| 卡片管理 | 卡片申请、额度调整、交易限额、冻结/解冻、卡片挂失（立即冻结 + 受理回执） |
| 订阅管理 | 从流水**自动识别**周期性扣费、续费倒计时提醒、一键取消订阅 |
| 跨场景联动 | 一句话安排生日：主动补问 → 锁定资金 → 鲜花/蛋糕下单 → 释放剩余 → 生成配送提醒 |

### 3.3 安全能力

1. **分级授权**：查询直接执行 / 中等风险点击确认 / ≥¥5,000 与高风险操作强制模拟短信验证码（2 分钟有效、错误 3 次锁定、拒绝重放）/ 涉诈黑名单**阻断级拦截**。
2. **风控规则引擎（10 条规则）**：收款人白名单、涉诈黑名单、金额阈值、夜间大额、整数大额、余额不足、单笔限额、日累计限额、收款人不存在、高风险话术。
3. **适当性管理**：以风险测评等级为准，超等级产品不推荐、不可申购，拒绝动作写审计。
4. **全程留痕**：成功、未就绪、失败、拒绝、取消、未识别意图六类全部入库，含风险等级、金额、原始请求、执行理由。
5. **知情同意与边界标注**：每步可解释；沙箱与真实环境的差异（模拟验证码、赎回 T+0、办卡仅到审核中）明确标注，**系统中不存在编造的执行结果**。

### 3.4 工程质量能力

| 能力 | 证据 |
| --- | --- |
| 自动化验收 | `npm run selftest` **264 项**、`npm run verify` **20 项**、`npm run rehearsal` **25 项**、安全探针（目录穿越 6 变体 / 异常输入 8 例 / 泄露检查 5 项 / 监听面）全部通过 |
| 可验证的数据真实性与持久化 | 用**独立进程读取磁盘文件**证明数据落盘；杀进程重启后审计编号连续、台账与对话完整 |
| 不依赖预埋标记的智能识别 | 评分制异常引擎在 303 笔支出中**独立复现**数据中预埋的全部 4 笔异常，零误报 |
| 一键彩排 | 按演示顺序自动跑完 6 个场景并计时，输出彩排报告（预计现场 180 秒内） |
| 零依赖可离线 | `npm install && npm start` 一条命令启动；不联网、不用数据库、不接真实接口 |

### 3.5 平台与集成能力

1. **数据可替换**：沙箱数据集中在 `mockdata.js`（确定性种子，可复现），替换为行内数据即可。
2. **执行通道可替换**：动作层是唯一动资金的地方，换成行内核心/开放平台接口即可，确认与留痕逻辑不需要改。
3. **模型可替换**：大模型走 OpenAI 兼容协议，可对接行内私有化模型；不配模型也能跑。
4. **策略可运营**：10 条规则与阈值集中在配置层，并保留每次判定的证据链。

## 四、能力边界（不做什么）

定位同样由边界定义。本作品**不做**：

1. **不碰真实资金**：全部为本地沙箱数据，不接任何真实支付、银行、商户接口。
2. **不给投资建议**：只做适当性过滤与产品事实呈现，不承诺收益、不做择时建议。
3. **不代替人工授权**：高风险操作由用户确认，系统只负责判定与留痕。
4. **不做最终风控裁决**：黑名单与规则来自业务方数据，系统承担前置拦截与解释，最终认定仍由风控/司法渠道负责。
5. **不假装能力**：未实现或受沙箱限制的能力一律如实标注。

## 五、应用场景

### 5.1 直接落地方向（产品）

| 场景 | 谁受益 | 价值 |
| --- | --- | --- |
| 手机银行 App 内嵌"AI 副驾" | 青年零售客群 | 把"找入口、填表单、读条款"压缩成一句话，提升活跃度与转化 |
| 远程银行/柜面坐席辅助 | 一线坐席与客户 | 坐席侧同步看到风控判定与操作留痕，减少误操作与合规风险 |
| 老年/新市民客群"一句话办事" | 数字鸿沟群体 | 口语化交互 + 关键信息大字卡 + 强制确认，降低使用门槛 |
| 反诈前置拦截 | 全量转账客户 | 陌生收款人、涉诈黑名单、夜间大额、整数大额在**资金流出前**拦截 |

### 5.2 能力复用方向（中台）

| 场景 | 复用点 |
| --- | --- |
| 适当性合规引擎 | 理财/基金代销、保险等产品的等级校验与拒绝留痕，可直接作为中台能力 |
| 操作留痕与质检 | 六类结果结构化入库，可用于客服质检、投诉复盘、监管报送 |
| 账单洞察 | 分类统计、环比、异常识别可复用于个人消费报告，也可扩展至小微对公流水 |
| Agent 安全脚手架 | 工具风险声明 + 待确认单 + 验证码 + 审计，可作为行内其他 Agent 的通用底座 |

### 5.3 教学与评审场景

1. **方案评审演示**：3 分钟内可完整演示六大场景 + 两个安全高光（风控拦截、跨场景全链路）。
2. **内部培训**：作为"AI 在金融场景如何守边界"的教学案例，每个机制都有可运行的证据。
3. **开发脚手架**：零依赖、单命令启动，适合作为行内 Agent 项目的起步模板。

## 七、宣传语备选

1. 稳妥版：面向青年客群的手机银行 AI 智能体，一句话办完业务，高风险操作强制确认、可疑交易主动拦截。
2. 安全侧重版：把风控与适当性做成门禁，而不是免责声明——不通过，连确认入口都不给。
3. 体验侧重版：从"找入口、填表单、读条款"到一句话完成，涉及钱的每一步都有人替你把关。
4. 技术侧重版：零依赖可离线运行的银行 Agent，双引擎容灾 + 264 项自动化断言 + 跨进程持久化验证。
5. 一句话收尾：**该拦的拦得住，该拒的拒得掉，该办的一步到位。**
