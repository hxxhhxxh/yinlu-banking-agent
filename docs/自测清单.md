## 三、边界与不做的事（答辩时主动说明，比被问出来更好）

1. **全部为本地沙箱数据**，不接任何真实支付/银行/商户接口（界面常驻"沙箱演示环境"）。
2. **短信验证码在沙箱直接显示**并标注"真实环境由短信下发"，真实实现不会回显。
3. **理财赎回按 T+0 到账**（沙箱加速），回执里明确标注真实环境为 T+1。
4. **办卡申请只到"审核中"**，不假装已发卡。
5. **定时转账只创建计划**，不模拟真实日期到达（沙箱不推进系统时间）。
6. **10 条风控规则 + 适当性**均以本地数据为准，接真实行内名单只需替换数据源。

## 四、已知环境注意事项

1. 端口被占用：启动时会明确提示，改 `.env` 的 `PORT` 即可。
2. 大模型未配置时自动使用**本地意图引擎**（离线演示模式），界面徽标会显示，这是容灾设计而非缺陷。
3. 演示前建议：全屏 + 缩放 100% + 窗口宽度 ≥1440px + 关闭消息通知。
4. 演乱了随时点「重置演示数据」，一秒回到初始态。
