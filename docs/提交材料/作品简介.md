# 作品简介

**作品名称**：银枢·AI银行副驾（YinShu AI Banking Copilot）

**一句话介绍**：让用户用一句大白话办完银行业务，同时让每一步资金变动都安全、可解释、可追溯。

---

## 一、作品定位

面向青年客群（18–35 岁）的手机银行智能体。用户不需要在层层菜单里找入口，只要说一句"给我妈转两千块交物业费""上个月的钱都花哪了""下周我妈生日帮我安排一下"，AI 副驾就会自主完成 **意图理解 → 任务规划 → 调用银行工具执行 → 结果反馈**，并在涉及资金、理财、挂失等敏感操作时，先把"要做什么、金额多少、风险是什么"讲清楚，再由用户二次确认。

金融场景的特殊性在于：**体验再好，一旦安全失守就是零分**。因此本作品把"安全"做成产品的一等公民，而不是免责声明。

## 二、六大核心场景

1. **智能转账**：按人名、昵称、手机号尾号、备注找收款人；转账前展示收款人、开户行、金额；定时转账、多人 AA 拆分收款、T+0 撤销最近一笔转账。
2. **账单分析**：消费自动分类统计、环比分析、消费时段分布；月度与年度账单报告；评分制异常交易识别（深夜大额、异地交易、金额突增、境外交易），每笔异常都给出风险分与可核对证据。
3. **理财操作**：先做风险测评（5 题问卷 → C1~C5），再做适当性过滤后推荐与对比，一键申购/赎回（含二次确认与风险提示朗读）。
4. **卡片管理**：卡片申请、额度调整、交易限额与冻结/解冻、卡片挂失（挂失后立即冻结并返回受理回执）。
5. **订阅/代扣管理**：从真实流水中自动识别周期性扣费，续费提前提醒，一键取消订阅。
6. **跨场景联动**：一句"下周我妈生日"，AI 主动补充询问日期、预算与偏好，随后锁定资金、自动完成鲜花与蛋糕预订，并生成配送提醒——全链路在一个对话里完成。

## 三、安全与合规设计（本作品的核心竞争力）

1. **三级权限分级**：🟢 绿色自动执行（纯查询）；🟡 黄色用户确认（小额转账当日累计 ≤¥1,000、订阅取消、虚拟卡申请）；🔴 红色多因子强验证（当日累计 >¥1,000 的转账、交易密码修改、卡片挂失/解挂、理财申购与赎回）——红色需**短信验证码 + 人脸识别**双因子，且在对话里回复“确认”无效，必须到确认卡片完成现场因子。
2. **风控规则引擎**：10 条规则独立判定（收款人不在常用名单、夜间大额、整数大额、涉诈黑名单、余额不足、超单笔/日限额、收款人不存在、高风险话术等），判定优先级为"硬阻断 > 业务拒绝 > 二次确认 > 直接执行"。命中涉诈黑名单属于**阻断级**——即使客户坚持也不放行，并提示拨打 96110。
3. **适当性管理**：理财推荐必须以风险测评等级为准，超等级产品不出现在推荐里、也不可申购，拒绝动作同样写入审计。
4. **全程留痕**：成功、未就绪、失败、拒绝、取消、未识别意图六类操作全部入库，字段包含操作名、风险等级、金额、原始请求与执行理由。
5. **知情同意**：Agent 每一步都可展开"为什么这么做"，让用户看懂而不是盲从。

## 四、技术特色

1. **零依赖可离线运行**：后端基于 Node.js 内置模块，前端为原生 HTML/CSS/JS，`npm install && npm start` 一条命令启动，全部为本地沙箱数据，不接任何真实支付接口。
2. **双引擎容灾**：默认使用内置本地意图引擎（断网也能演完整流程），配置大模型后自动切换；大模型超时或报错会自动降级，演示不中断。
3. **过程可见的 Agent**：所有思考与工具调用以事件流实时推送（think → intent → plan → tool_call → tool_result），区别于普通聊天机器人。
4. **可验证的质量体系**：内置 336 项单元/集成断言、20 项真实链路与持久化专项验证、25 项全链路彩排断言；异常识别引擎能够在完全不依赖预埋标记的前提下，独立复现数据中预埋的全部 4 笔异常且零误报。

## 五、创新点

1. **安全从"提示语"变成"门禁"**：适当性与风控不通过时，连确认入口都不生成，从机制上避免用户被自己的一时冲动带走。
2. **把"承诺合规"变成"可验证合规"**：每一条安全机制都有对应的自动化断言与界面证据，可现场逐条核对。
3. **跨场景服务编排**：把银行业务与本地生活服务打通，"锁定资金 → 下单 → 释放剩余 → 生成提醒"形成闭环，金额完全守恒。
4. **诚实的边界管理**：沙箱环境把"模拟短信验证码""赎回 T+0 加速""办卡仅到审核中"等差异在界面与回执中明确标注，绝不假装能力比实际更强。

## 六、应用价值

对青年用户：把"找入口、填表单、读条款"压缩成一句话，同时避免被诈骗话术和高风险产品伤害。
对银行：一方面降低柜面与客服压力、提升年轻客群活跃度；另一方面把分散在制度文件里的风控与适当性要求，落成可运行、可审计、可演示的系统能力。

**补充能力**：同时接入 APP 主界面与 IM 文本通道；支持"回退上一步"撤销上一笔可逆操作、以及转人工接管；复杂请求会拆解为子任务 DAG 依次执行。项目内置路由审计工具（`npm run audit`），用现场台词逐条验证理解准确性。
